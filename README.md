# DixlaseCookie

DixlaseCookie is a plugin for Dixlase (and also composer-ready for future distribution).

## Installation

1. Copy to the `plugins/DixlaseCookie` directory of your CMS.
2. (Optional) Run `composer install` if needed.
3. (Optional) Enable the plugin in the CMS admin panel.
