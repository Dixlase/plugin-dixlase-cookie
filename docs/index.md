# DixlaseCookie プラグイン

## 概要

**DixlaseCookie** は、GDPR / 電気通信事業法（改正）等の同意取得ルールに対応した Cookie 同意管理プラグインです。訪問者がサイトを開いたとき、必要な Cookie カテゴリを選択できる同意バナーを表示します。

## 主な特徴

- **カテゴリ別同意**: 必須 / 機能 / 分析 / マーケティング の 4 カテゴリで、訪問者ごとの選択を保存
- **持続する再オープン導線**: ページ右下（テーマにより位置は異なる）の「Cookie」ボタンからいつでも設定を変更・撤回可能
- **コア連携（ConsentStateProvider 契約）**: 他プラグイン（例: SEO / Google アナリティクス）が同意状態を参照し、トラッキングのオン/オフを自動制御できる
- **同意バージョン管理**: プライバシーポリシーを改定したとき、管理画面から「バージョン bump」で全訪問者に再同意を求められる
- **ポリシーリンク**: バナー内にプライバシーポリシー / クッキーポリシーへのリンクを任意設定可能

## Cookie カテゴリ

| カテゴリ | 用途 | 訪問者操作 |
| --- | --- | --- |
| **必須** | サイト機能の維持（ログイン維持、CSRF 保護、言語設定等） | 常に有効。オフにできません |
| **機能** | 訪問者の利便性向上（テーマ設定、閲覧履歴等） | 訪問者が選択 |
| **分析** | サイトの利用状況の集計（ページビュー、遷移経路等） | 訪問者が選択 |
| **マーケティング** | 広告配信・サイトを跨いだトラッキング | 訪問者が選択 |

## いつ使うか

- 日本国内で運営し、電気通信事業法に対応したい
- EU / EEA / 英国の訪問者を含む可能性があり、GDPR に準拠したい
- Google Analytics / Facebook Pixel / Google Ads 等の**同意ベースの計測**を導入したい
- 訪問者が「後から同意を撤回できる」導線を提供したい

## いつ不要か

- 同意対象の Cookie を一切使っていない（分析 / 広告 / 埋め込みメディア等がない）純粋な静的サイト
- 認証・セッション以外の Cookie を発行していない社内向けサイト

## 他プラグインとの連携

DixlaseCookie は Core の `ConsentStateProvider` 契約を実装します。他プラグイン（SEO / アナリティクス系）は同意状態を通じて次のような制御が可能：

```
if (consent()->allows('analytics')) {
    // Google Analytics のスクリプトを読み込む
}
```

同意状態が変更されると、ページを再読込するかフロント JS で該当トラッカーの有効化 / 無効化を切り替える仕組みです。
